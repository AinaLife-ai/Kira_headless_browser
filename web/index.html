接入令牌

扩展需要一枚令牌才能连接。令牌与 KiraAI 的鉴权状态绑定：重启、轮换 access_token 之后需要重新生成。
「重新生成」会让所有旧令牌立即失效（当场作废，不是等它过期）， 然后签出一枚新令牌 —— 你必须把它重新粘贴到扩展里。

如何接入

  1. 在 Chrome / Edge 打开 chrome://extensions，打开右上角「开发者模式」
  2. 点「加载已解压的扩展程序」，选择 browser-bridge 文件夹
  3. 点扩展图标，把上面这枚令牌粘贴进去，保存
  4. 扩展会自动连接，本页状态变为「已连接」
